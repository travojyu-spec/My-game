# Состояние игры после реализации вступления

Пользователь поручил ChatGPT закончить всё самостоятельно. Вступление уже реализовано, повторно подключать графику и писать эту главу с нуля не требуется.

Прочитать [AGENTS.md](AGENTS.md), [README.md](README.md) и [актуальную передачу](handoff/chatgpt-to-claude.md).

Вход — `src/main.ts`; новый код главы — `src/adventure/`. Три боя, бесплатные сюжетные спутники, две постоянные наёмницы за игровое золото, резерв и сохранение прогресса подключены к Phaser. Каталог `public/assets/chatgpt/manifest.json` содержит 42 оригинальных PNG, включая пять выбранных героев. Однофайловая сборка встраивает этот же каталог.

Следующая проверка: реальный мобильный вид, перекрытия и зоны касания, затем баланс с живым игроком. Браузерный предпросмотр во время реализации был заблокирован автоматической проверкой доступа из-за лимита сервиса, поэтому визуальная приёмка не заявляется. Автоматические проверки доступны через `npm test`, `npm run build` и `npm run build:single`.

Выбранные мастера не уменьшать, не сокращать палитру и не заменять старыми архетипами. После первой победы бесплатно приходят Фрирен и Ферн, после второй — Мэгумин и Убийца гоблинов. Только Нара и Мира нанимаются за золото.

Код можно развивать в обычной зоне Claude. Результат и запросы на графику записывать только в собственный `handoff/claude-to-chatgpt.md`.
