# Перекрёсток миров

Пошаговая партийная RPG для телефона в духе Knights of Pen & Paper 2.
Отряд из 4 героев аниме проходит 12 миров их произведений: карта этапов, города, привалы, события, боссы.
Phaser 4.2.1 + TypeScript + Vite. Горизонтальный экран, управление касаниями.

- Играть: https://travojyu-spec.github.io/My-game/
- Пробная версия (ветка `test`): https://travojyu-spec.github.io/My-game/test/

## Команды

```bash
npm ci               # зависимости строго по package-lock.json
npm run dev          # разработка: http://localhost:5173 (доступно и с телефона в той же сети)
npm run build        # сборка в dist/
npm run build:single # всё в одном dist-single/index.html — открывается даже с диска
npm test             # оригиналы графики не изменены + быстрый прогон боёв
npm run sim          # прогон кампаний без графики: ошибки в умениях и баланс (npm run sim 20 1)
npm run assets       # обновить ASSETS_TODO.md — список картинок, которых пока нет
```

## Что в игре

- **25 героев** с пассивкой, 3–6 умениями, ультой и деревом прокачки (3 ветки × 5 навыков).
  Герои открываются по сюжету: в старте Аква, Даркнесс и Мэгумин, остальные встречаются в своих мирах.
- **Сыгранность**: герои из одного произведения усиливают друг друга (Коносуба, Мугивары, Грехи, Безработный и др.),
  есть и перекрёстные пары (Аква + Алукард, Эсканор + Камина, Гатс + Алукард, Санджи + Сэнши).
- **12 регионов**: Аксель, Подземелье, Клевер, Северные земли, Британия, Шангри-Ла, Демонический континент,
  Гранд Лайн, Аместрис, Лондон, Мидланд, Поверхность. В каждом — монстры и босс из оригинала со своей механикой
  (проклятие смерти Бельдии, регенерация Данте, подчинение Ауры, логия Крокодайла, жизни Похоти…).
- **Между боями**: город (отдых, таверна, магазин, кузница, задание, охота), привал, события с выбором.
- Здоровье переносится между боями, мана — нет. Шкала Предела копится в бою и открывает ульту.
- Сохранение автоматическое (localStorage).

## Бой

- Внизу — умения текущего героя и «Сумка» (предметы и «Оборона»). Ульта подсвечена, когда шкала полна.
- Касание умения — описание, цена и прогноз урона наверху; цель меняется касанием бойца.
- «Применить» или повторное касание выбранной цели — выполнить. Недоступное умение объясняет причину.
- Касание бойца или иконки в очереди слева — здоровье, статусы, сопротивления, особенности.
- Справа вверху: звук, скорость ×1/×2, полный экран, отступление.

## Устройство

```
src/
  battle/core.ts     движок боя без графики: урон, статусы, очередь, хуки умений
  data/kit.ts        описание героя, сыгранность
  data/heroesA.ts    защитники и бойцы (12)
  data/heroesB.ts    маги и поддержка (12)
  data/enemies.ts    монстры и боссы, ИИ врагов
  data/regions.ts    регионы, этапы, события, магазин
  game/progress.ts   сохранение, рост героев, сборка боя, награды
  scenes/            BootScene (загрузка), BattleScene (арена и анимации)
  ui/app.ts          экраны между боями (DOM): карта, город, герои, таверна
scripts/             simulate.ts (баланс), assets-todo.ts (список визуала)
public/assets/       графика ChatGPT, Tiny5, manifest.json
```

Графику рисует ChatGPT (`public/assets/chatgpt/`, правила — в `AGENTS.md`), связи с героями и монстрами — `src/game/art.ts`.
Нет картинки — игра рисует заглушку (цветной квадрат с инициалами). Что ещё нужно нарисовать — `ASSETS_TODO.md`.

## Публикация

`.github/workflows/pages.yml`: пуш в `main` обновляет корень сайта, пуш в `test` — папку `/test/`.
Новые версии сначала выходят пробными в `/test/`, основной сайт меняется только после проверки.
