# Лесная дорога

Первая играбельная глава мобильной RPG на Phaser + TypeScript + Vite. Игра открывается обычным сайтом, телефон держать горизонтально.

- [Играть](https://travojyu-spec.github.io/My-game/)
- [Однофайловая версия](https://travojyu-spec.github.io/My-game/offline.html) — сохранить HTML для запуска без сети.

## Что есть в игре

Начало в привале у ручья с одним Старком. Три последовательных поручения: один гоблин на опушке, гоблин с бронированным громилой на тропе и страж с гоблином и лекарем у шлюза. После первого боя бесплатно присоединяются Фрирен и Ферн, после второго — Мэгумин и Убийца гоблинов.

За первые победы выдаются 30, 60 и 90 золотых. После главы в таверне доступны постоянные наёмницы: табакси-лучница Нара за 90 и дженази-целительница Мира за 120. Повторный контракт у шлюза приносит 20 золотых. Основная пятёрка бесплатна; реальных платежей нет. В активном отряде 1–5 героев, остальные в резерве.

Каждый герой имеет две способности. Броня грибов ослабляет физический урон, магия проходит сквозь неё, огонь усиливается. Громила предупреждает о замахе; барьер и прикрытие помогают пережить удар. Взрыв Мэгумин поражает всех врагов и выводит её из очереди до конца боя. Лекарь врагов восстанавливает здоровье союзникам.

Управление: выбрать способность, нажать на врага или союзника, затем «Применить». В первом бою цель уже выбрана. HP и MP восстанавливаются между боями. Поражение позволяет повторить бой без потери золота и спутников.

Золото, прохождение, нанятые герои и состав отряда сохраняются в localStorage (`my-game/campaign/v1`). Перезагрузка страницы во время боя возвращает к привалу перед поручением. Сами незаконченные ходы не сохраняются. Сохранения относятся к конкретному браузеру и адресу сайта. Настройка звука использует прежний ключ `pnp-battle/settings`.

## Разработка и проверки

```bash
npm ci
npm run dev
npm test
npm run build
npm run build:single
```

`npm test`: 300 боёв трёх поручений с разными seed, бой с наёмницами, награды без дублирования, найм, резерв, очистка повреждённого сохранения, запрет чужого хода, барьер и прикрытие, 42 контрольные суммы оригинальных изображений.

Обе сборки проходят проверку TypeScript. В этой поставке браузерная проверка мобильного вида и касаний не выполнена: автоматическая проверка доступа к предпросмотру была заблокирована лимитом сервиса. Это остаётся отдельной проверкой, прохождение тестов логики её не заменяет.

## Устройство проекта

| Путь | Назначение |
| --- | --- |
| `src/adventure/content.ts` | Герои, способности, враги, три поручения, награды |
| `src/adventure/campaign.ts` | Прогресс, золото, постоянный наём, резерв и сохранение |
| `src/adventure/app.ts` | Переходы между привалом и боем, доступный HTML-интерфейс, управление касаниями |
| `src/adventure/scene.ts` | Мир и эффекты Phaser, отдельные изображения объектов, точки опоры и масштабирование |
| `src/adventure/game.css` | Мобильный интерфейс и окно поворота телефона |
| `src/battle/` | Правила пошагового боя без зависимости от Phaser |
| `public/assets/chatgpt/manifest.json` | Каталог всех 42 используемых/доступных PNG и метаданные опоры |
| `art/chatgpt/` | Мастера, решения по графике, описание главы |

Старые `src/scenes/BootScene.ts`, `BattleScene.ts` и исходный каталог оставлены для истории прототипа, новый вход `src/main.ts` их не запускает. Реестры `ABILITIES` и `UNIT_BY_ID` дополняются контентом главы; прежний массив `UNITS` и старый симулятор сохранены.

## Графика и совместная работа

Выбор пользователя сохранён: **Фрирен 3, Ферн 3, Старк 1, Мэгумин 2, Убийца гоблинов 2**. Семь новых объектов привала и найма выбраны ChatGPT после поручения «сделай всё сам». Файлы мастеров и игровые копии совпадают побайтно. Палитра и исходное разрешение не сокращались, размер меняется только при отображении. Для окон используется ранее выбранный скин 1, шрифт Tiny5 с кириллицей (OFL).

Обычные границы работы с Claude находятся в [AGENTS.md](AGENTS.md); эта реализация кода выполнена ChatGPT по прямому поручению пользователя. Актуальное состояние и передача — [CLAUDE_TASK.md](CLAUDE_TASK.md) и [handoff/chatgpt-to-claude.md](handoff/chatgpt-to-claude.md). Чужой исходящий файл не изменялся.

## Публикация

После изменения `main` GitHub Actions запускает тесты, собирает обе версии, копирует single-версию в `offline.html` и публикует `gh-pages`. Пути относительные, сайт работает в подпапке `/My-game/`. Сборки `dist/` и `dist-single/` являются производными; исходники выше — источник истины.

В дальнейшем сайт можно упаковать в Android-приложение через Capacitor: игровая логика и Phaser не требуют переписывания. Сетевой синхронизации сохранений и аккаунтов сейчас нет.
