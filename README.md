# Бой у старого шлюза

## Совместная работа и новая графика

Код и публикация — Claude; графика — ChatGPT. Границы папок и порядок синхронизации описаны в [AGENTS.md](AGENTS.md).

Утверждены Фрирен 3, Ферн 3, Старк 1, Мэгумин 2 и Убийца гоблинов 2. Их исходники и остальные выбранные ресурсы переданы в [art/chatgpt](art/chatgpt/) и [public/assets/chatgpt](public/assets/chatgpt/). Задача подключения — в [CLAUDE_TASK.md](CLAUDE_TASK.md), подробности — в [передаче Claude](handoff/chatgpt-to-claude.md).

Ниже описан существующий прототип; новый набор графики подключается отдельной работой Claude.

Мобильный прототип пошагового боя в духе Knights of Pen & Paper 2.
Phaser 4.2.1 + TypeScript + Vite. Горизонтальный экран, управление касаниями.

## Команды

```bash
npm ci               # установить зависимости строго по package-lock.json
npm run dev          # разработка: http://localhost:5173, доступно и с телефона в той же сети
npm run build        # сборка в dist/ (файлы + относительные пути)
npm run build:single # всё в одном dist-single/index.html — открывается даже с диска, без сервера
npm run preview      # проверить готовую сборку dist/
npm run sim          # прогон 2000 боёв без графики для проверки баланса
```

Версии зависимостей зафиксированы точно (без `^`), lock-файл в проекте.

## Управление

- Внизу справа — две кнопки действий текущего героя: базовая атака и умение.
- Касание кнопки выбирает действие: наверху появляется описание, цена в мане и прогноз («→ Гоблин: −5»).
- Подходящие цели обведены кольцом, выбранная — золотыми уголками. Цель меняется касанием бойца.
- «Применить» или повторное касание выбранной цели — выполнить. Повторное касание действия — отмена.
- Недоступное действие можно нажать: наверху появится причина («Не хватает маны…», «Все союзники здоровы…»).
- Касание любого бойца или портрета в очереди слева — его здоровье, мана и особенности.
- Справа вверху — полный экран и звук. В портретной ориентации игра просит повернуть телефон.

## Правила первого боя

Все числа временные и собраны в `src/config/balance.ts`.

| Боец | ОЗ | Мана | Действия |
| --- | --- | --- | --- |
| Воин | 38 | 4 | Удар 6 · Защита (2 маны): принимает удары за союзника, получая половину урона |
| Маг | 22 | 10 | Посох 3 · Огненный шар (4 маны): 8 огнём, броневику ×1,5 |
| Лучник | 26 | 6 | Выстрел 5 · Меткий выстрел (3 маны): 9 |
| Лекарь | 26 | 9 | Посох 3 · Лечение (3 маны): +10 |
| Гоблин | 18 | — | Рогатка 5 по самому раненому герою |
| Гриб-броневик | 46 | — | Броня: обычный урон ×½. Замах на героя, следующим ходом удар 16 |
| Гриб-лекарь | 22 | — | Лечит раненого союзника на 9, иначе споры 4 |

Герои восстанавливают 1 ману в начале своего хода. Порядок ходов — по скорости,
побеждённые пропускают ход. Тактика: убрать гриба-лекаря, жечь броневика огнём,
прикрывать воином цель замаха. Симуляция: тактичная игра побеждает всегда,
случайная — примерно в половине боёв, только базовыми атаками — почти никогда.

## Устройство

```
src/
  battle/        логика боя без Phaser: состояние, правила, ИИ врагов, события
  config/        баланс: бойцы, умения, числа
  core/          экран и масштаб, ассеты, звук, настройки, полный экран
  scenes/        BootScene (загрузка) и BattleScene (арена, интерфейс, анимации)
  ui/            кнопки, панели, шрифт и цвета
scripts/simulate.ts   проверка баланса
public/assets/        графика и Tiny5 из передачи ChatGPT, manifest.json
```

Логика возвращает список событий (урон, лечение, замах, смерть), сцена проигрывает их по порядку.
Состояние боя — простой объект с полем `version`, его можно сохранять как есть.

### Экран и пиксели

- Холст рисуется в физическом разрешении телефона, мир 480×270 масштабируется камерой.
  Режим `smoothPixelArt` даёт одинаковые чёткие пиксели при дробном масштабе.
- Ширина видимой области подстраивается под пропорции экрана (16:9 … 21:9 и шире),
  по краям фон продлевается зеркально. Интерфейс прижат к краям с учётом выреза камеры
  и системных панелей (`env(safe-area-inset-*)`).
- Tiny5 используется размерами 16 и 24 (кратны 8 — без искажений), загружается до создания текста.
- Зоны касания: кнопки 42 единицы, бойцы не меньше 40×48 — это 50–60 CSS px на телефонах.

### Пауза и звук

- При сворачивании бой замирает (таймеры, анимации, звук). После возврата — экран «Пауза»,
  касание продолжает бой с того же места хода.
- Повторные и быстрые касания во время действия игнорируются, двойное «Применить» засчитывается один раз.
- Звук синтезируется через Web Audio (файлов нет), включается первым касанием, выключатель сохраняется.

## Публикация

Игра: https://travojyu-spec.github.io/My-game/
Версия одним файлом для игры без интернета: https://travojyu-spec.github.io/My-game/offline.html

Сайт обновляется сам: после каждого изменения в `main` GitHub Actions собирает игру
и кладёт сборку в ветку `gh-pages` (`.github/workflows/pages.yml`).

`dist/` можно выложить в корень сайта или в любую подпапку (GitHub Pages, свой хостинг):
пути относительные. Адрес подпапки должен заканчиваться на `/`.

`dist-single/index.html` — один файл со встроенной графикой и шрифтом, работает без сервера и сети.

## Переход к Android-приложению (Capacitor)

Когда дойдёт до упаковки:

```bash
npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Бой у шлюза" com.example.sluice --web-dir dist
npm run build && npx cap add android && npx cap sync
```

Что проверить: фиксация горизонтали в `AndroidManifest.xml`, звук после сворачивания,
системные отступы, хранилище настроек (`src/core/settings.ts` — замена в одном месте).

## Что стоит дорисовать

- Иконка лука для лучника — сейчас временная, нарисована кодом в `BootScene.ts` в палитре иконки меча.
- Значки звука и полного экрана нарисованы кодом пиксельными матрицами в `BattleScene.ts`.
- Портреты в очереди ходов — вырезки из спрайтов (координаты в `PORTRAIT`).

Шрифт Tiny5 — лицензия OFL, файл лицензии лежит рядом с TTF.
