# Совместная работа над My-game

Игра для телефона: Phaser + TypeScript + Vite, запуск в браузере. Программированием занимается Claude, графикой и проверкой визуала — ChatGPT. Явные задачи пользователя имеют приоритет над обычным разделением ниже.

## Разделы проекта

| Раздел | Основной автор | Назначение |
| --- | --- | --- |
| `src/`, `scripts/`, `index.html`, конфигурация сборки, зависимости, `.github/` | Claude | Игра, интерфейс, баланс, загрузка, сборка и публикация |
| `art/chatgpt/` | ChatGPT | Утверждённые оригиналы, выбор пользователя, промпты, референсы |
| `public/assets/chatgpt/` | ChatGPT | Доставленный набор PNG и каталог для подключения в игре |
| `handoff/chatgpt-to-claude.md` | ChatGPT | Готовые поставки графики и задачи на подключение |
| `handoff/claude-to-chatgpt.md` | Claude | Результат интеграции, найденные визуальные проблемы и запросы на графику |

Claude меняет загрузчик и использование графики в коде. Изображения, их палитру и исходное разрешение меняет ChatGPT по задаче на графику. Новые файлы для игры передаются в `public/assets/chatgpt/`; ранее существующие `public/assets/` остаются частью текущего прототипа до его перевода на новый каталог.

## Перед началом работы

1. Получить актуальную `main` и прочитать входящий файл в `handoff/`.
2. Проверить `git status` и не включать в свой коммит чужие незавершённые изменения.
3. Источник выбора графики — `art/chatgpt/selection.json`. Актуальная задача для Claude — `CLAUDE_TASK.md`.
4. Сверить затрагиваемые пути с таблицей. Если задача требует обе стороны, описать согласованный переход во входящем файле; не переносить весь проект между папками.

## Параллельная работа

Для продолжительной параллельной работы использовать ветки `art/chatgpt-<задача>` и `game/claude-<задача>`, созданные от актуальной `main`. Короткие проверенные передачи графики можно добавлять в `main` отдельным коммитом. Перед отправкой получить новые изменения, сохранить чужие коммиты, не применять force-push к `main` или чужой ветке.

Один автор обновляет один исходящий файл: ChatGPT — `chatgpt-to-claude.md`, Claude — `claude-to-chatgpt.md`. Не писать ответы поверх файла другого автора. Сборки `dist/`, `dist-single/` и ветка `gh-pages` относятся к сборке/публикации Claude; графику передавать исходными файлами, а не правками готового HTML.

## Качество графики

- Хранить выбранные мастер-PNG неизменными. В поставке их копии совпадают побайтно с утверждёнными генерациями.
- Пользователь отклонил автоматически уменьшенные кадры 64×80 и сокращение палитры до 32 цветов: эта обработка уничтожила детали. Не воспроизводить её для игровых файлов, сравнений или портретов.
- Масштаб отображения настраивать в игре с проверкой на телефоне; не запекать маленький испорченный PNG. Проверять причёски, заколку Ферн, посохи и целостность топора Старка.
- Каждый объект сцены остаётся отдельным элементом. Новые художественные изображения создаёт ChatGPT через ImageGen.
- У пяти новых героев сейчас по одному кадру со спины. Лицевых портретов и покадровых анимаций этот набор не содержит. Запрашивать недостающую графику через исходящий файл Claude.

## Проверка

Для изменений каталога проверять существование файлов, размеры и сохранность выбранных PNG. Для интеграции в игру выполнить `npm run build` и `npm run build:single`, проверить загрузку относительно подпапки сайта, касания, кириллицу и вид на телефоне. Успешная сборка сама по себе не подтверждает качество рисунка.
