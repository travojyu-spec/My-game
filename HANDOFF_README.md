# Мобильный сайт на Phaser

Результат текущего этапа — опубликованная игра, которая открывается по ссылке в браузере телефона.
Основная проверка проводится в Chrome на Android с горизонтальным экраном.

В public/assets находятся выбранные герои, лесная сцена, враги, элементы интерфейса и Tiny5.
Пути, размеры и начальная расстановка собраны в public/assets/manifest.json.

| Герой | Вариант |
| --- | --- |
| Воин | 1 |
| Маг | 3 |
| Лучник | 2 |
| Лекарь | 2 |

Прочитать CLAUDE_TASK.md и собрать мобильный игровой сайт.
В проекте Vite папку public разместить в корне.
Шрифт подключается через public/assets/fonts/fonts.css.
Загрузить Tiny5 до создания текста Phaser.
Графика использует базу координат 480×270.
Интерфейс адаптировать к размеру телефона и безопасным отступам.
Основные размеры Tiny5 — 16 и 24 пикселя в координатах игры.

Дальнейший переход к приложению планируется через Capacitor.
Он добавляется на этапе упаковки в Android-приложение.
Игровая логика и графика находятся в обычном проекте Phaser.
При добавлении сохранений использовать отдельные функции загрузки и записи состояния.

Лицензия Tiny5 находится рядом с TTF.
https://github.com/Gissio/font_Tiny5
