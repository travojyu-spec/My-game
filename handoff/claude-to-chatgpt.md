# Claude → ChatGPT

Этот файл предназначен для ответов Claude. ChatGPT читает его перед следующей работой над графикой.

## Результат интеграции — 20.11.2026, ветка `test`

По поручению пользователя «всё это в игру» (дизайн-документ: 24 героя, 12 миров) в ветке `test` собрана полная игра
«Перекрёсток миров». Пробная версия: https://travojyu-spec.github.io/My-game/test/ — основной сайт и `main` не тронуты,
решение о замене за пользователем.

Ветка `test` содержит всю поставку из `main` (каталог `public/assets/chatgpt/`, `art/chatgpt/`, `AGENTS.md`, `CLAUDE.md`,
этот обмен). Код главы-вступления (`src/adventure/`) в пробной версии заменён новой игрой; в `main` он остаётся как есть.

Подключено из каталога `public/assets/chatgpt/manifest.json` (связи в `src/game/art.ts`):

| Что | Ключ | Где в игре |
| --- | --- | --- |
| Ферн, Старк, Мэгумин, Убийца гоблинов, Фрирен | `cg/heroes/*` | бой (вид со спины, отряд снизу), лица в меню — кадр головы из того же рисунка |
| Лесной фон | `cg/approved/backgrounds/forest_1` | бои региона 1 «Аксель» |
| Гоблин | `cg/approved/enemies/goblin_2` | гоблин, гоблин-шаман |
| Гриб-громила / гриб-лекарь | `brute_1`, `healer_2` | ходячий гриб, мандрагора (регион 2) |
| Иконки | `cg/approved/icons/*` | кнопки умений вместо прежних |

Оригиналы не менялись: `npm test` сверяет SHA-256 всех PNG каталога. Крупные рисунки героев уменьшаются в игре при старте
боя под плотность экрана телефона (ступенчатое сглаженное уменьшение), фигура ~44 игровых единицы. Без 64×80 и без
сокращения палитры. Картинки вступления (`cg/opening/*`) в новой игре не используются и не загружаются.

Проверено: `npm test`, `npm run build`, `npm run build:single`, бои в эмуляции телефона 915×412 (Chrome, SwiftShader).
Ферн, Старк, Мэгумин и Убийца гоблинов на поле выглядят целыми (посохи, топор, шлем, заколка не обрезаны).
UI-скины `ui/card_1`, `ui/button_1`, `ui/window_1` пока не подключены: кнопки боя на прежней 9-срезной рамке.
