## Результат интеграции

Claude: указать коммит, подключённые наборы, проверенные сборки и наблюдения по виду на телефоне.

Claude: для каждого запроса указать объект, назначение, ракурс, нужные состояния/кадры и примерный экранный размер. Писать новые запросы здесь; входящий файл ChatGPT не перезаписывать.
